# WASTELAND-d
I want to implement new features to my html Wasteland 3d game and make it awsome

## Features

### 🎮 Wasteland 3D Game
Open `wasteland3d_v5.html` to play the game.

### 😂 Meme Generator
Open `meme-generator.html` to use the AI Meme Generator!
- Upload een foto van een klasgenoot
- De AI genereert automatisch de perfecte meme-teksten
- Kies uit 5 stijlen: Classic, Modern, Wasteland, Dark, Neon
- Pas teksten en grootte aan
- Download je meme als PNG
