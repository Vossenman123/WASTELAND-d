The app uses api.js as a data abstraction layer. By default it reads from localStorage. To connect Firebase or Laravel REST, edit api.js and set:

api.js – top of file const API_CONFIG = { useBackend: true, // ← enable backend mode provider: 'firebase', // or 'laravel' baseUrl: 'https://your-app.test/api', // required for laravel token: null, };

Laravel option: keep using the following routes/api.php shape:

Route::post('/login', [AuthController::class, 'login']); Route::post('/logout', [AuthController::class, 'logout']) ->middleware('auth:sanctum'); Route::middleware('auth:sanctum')->group(function () { Route::apiResource('exercises', ExerciseController::class); Route::apiResource('workouts', WorkoutController::class); Route::apiResource('templates', TemplateController::class); Route::apiResource('friends', FriendController::class); Route::get ('prs', [PrController::class, 'index']); Route::put ('prs', [PrController::class, 'update']); Route::get ('settings', [SettingsController::class, 'show']); Route::put ('settings', [SettingsController::class, 'update']); });

Firebase option uses Firebase Auth + Firestore through the same GymApi methods. Laravel option uses JSON REST + Sanctum bearer tokens. When useBackend: false every call reads/writes localStorage directly — no network required.
